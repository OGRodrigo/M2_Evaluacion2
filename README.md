# 🎮 Level Up Store

Level Up Store es un e-commerce desarrollado con React para la Evaluación 2 del Módulo 2 del Diplomado Full Stack.

El proyecto mantiene la identidad visual gaming de la evaluación anterior y consume productos dinámicamente desde la API pública DummyJSON.

## Componentes creados

- Header
- SearchBar
- ProductCard
- ProductList
- Loader
- ErrorMessage
- Footer

Cada componente se encuentra dentro de su propia carpeta y posee su propio archivo CSS.

## Funcionalidades

- Consumo de productos desde `https://dummyjson.com/products`
- Búsqueda de productos por nombre
- Estado de carga con `Loader`
- Estado de error con `ErrorMessage`
- Renderizado dinámico de productos
- Diseño responsive para desktop, tablet y mobile

## Tecnologías utilizadas

- React
- JavaScript
- HTML5
- CSS3
- Vite
- Git
- GitHub
- DummyJSON

## Cómo ejecutar el proyecto

1. Clonar el repositorio:

```bash
git clone https://github.com/OGRodrigo/M2_Evaluacion2.git
```

2. Entrar a la carpeta:

```bash
cd M2_Evaluacion2
```

3. Instalar dependencias:

```bash
npm install
```

4. Ejecutar:

```bash
npm run dev
```
